# U-Net on the teacher labels: implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or
> superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Train a U-Net on `labels_teacher.zarr`, track it with MLflow, and score it against the station truth with
the full-count POD / FAR / CSI and the blocked folds.

**Architecture:** `unet.py` (network), `unet_data.py` (inputs, targets, folds, station points), `unet_train.py`
(loss, training, saved model, labels), `unet_cv.py` (cross-validation over night folds), `tracking.py` (MLflow),
`unet_predict.py` (prediction store), `unet_eval.py` (held-out comparison); three commands `fogseg train`,
`fogseg predict`, `fogseg evaluate`. Scoring reuses `experiment.py` and `teacher.py`.

**Tech Stack:** Python 3.11+, PyTorch, MLflow, xarray / Zarr v3, pandas, pytest, ruff 0.17.

**Spec:** `docs/superpowers/specs/2026-11-07-unet-design.md` (rulings U1–U13).

## Review Focus

1. **A store or model made from other data** (rebuilt dataset, other label store, other model file): every command
   refuses with a message naming what to rerun; never scores silently.
2. **Scenes outside the fit**: no scene of night fold 5, of the CV test fold, or of the test season ever reaches a
   training batch; tested on the fold arrays, not just on the counts.
3. **NaN brightness temperatures** (1,238 in the real data) and twilight pixels: inputs finite everywhere, loss
   never NaN, probability NaN and label 255 there.
4. **Odd scene sizes** (241 × 462): padding to a multiple of 2^depth and cropping back keeps pixel (iy, ix) at
   (iy, ix); a station point lands on its own pixel after padding.
5. **A rerun after the held-out look**: `train` and `evaluate` refuse once `unet_held_out.*` exist.

### Task 4: Loss, training, saved model and labels

**Files:**
- Create: `src/fogseg/unet_train.py`, `tests/test_unet_train.py`

**Interfaces:**
- Consumes: `UNet` (Task 2), `INPUT_CHANNELS`, `Normalization` (Task 3), `labels.NO_FOG/FOG/OBSCURED/IGNORE`.
- Produces:
  - `@dataclass(frozen=True) class UNetParams` with the `unet:` keys of the spec (`model_path`, `predictions_path`,
    `tracking_uri`, `artifact_dir`, `experiment`, `base_channels`, `depth`, `epochs`, `batch_size`,
    `learning_rate`, `weight_decay`, `point_weights`, `probability_grid`, `device`) and
    `from_config(unet_cfg: dict) -> UNetParams`. Add the `unet:` section of spec §5 to `configs/default.yaml`.
  - `unet_settings(point_weights: list[float]) -> list[tuple[str, dict]]`: `[("1 soft", {"target": "soft",
    "point_weight": 0.0}), ("2 hard", {"target": "hard", "point_weight": 0.0}), ("3 soft points 0.25", {"target":
    "soft", "point_weight": 0.25}), ("4 soft points 1", {"target": "soft", "point_weight": 1.0})]` for `[0.25, 1.0]`
    (numbers continue from 3; weights printed with `:g`).
  - `choose_device(name: str) -> torch.device`: `auto` → cuda if available, else cpu with a logged warning;
    `cpu` / `cuda` as given.
  - `masked_bce(logits, target, weight) -> Tensor`: weighted mean binary cross-entropy with logits over pixels of
    weight 1; `0.0` (with grad) when no pixel has weight.
  - `point_bce(logits, batch: Tensor, iy: Tensor, ix: Tensor, truth: Tensor) -> Tensor`: mean cross-entropy at the
    points; `0.0` when there are none.
  - `train_model(inputs: np.ndarray, target: np.ndarray, weight: np.ndarray, points: pd.DataFrame, options: dict,
    params: UNetParams, seed: int, device: torch.device, monitor: tuple[np.ndarray, np.ndarray, np.ndarray] | None
    = None, on_epoch: Callable[[int, float, float | None], None] | None = None) -> UNet`. `points` index `inputs`
    by `scene`. Per spec U6: AdamW, `CosineAnnealingLR(T_max=epochs)`, shuffled batches from
    `torch.Generator().manual_seed(seed)`, `torch.manual_seed(seed)`, loss `masked_bce + point_weight *
    point_bce`. After each epoch `on_epoch(epoch, mean train loss, monitor loss or None)`; the monitor loss is
    `masked_bce` of the model in eval mode on the `monitor` inputs, target, weight.
  - `predict_probabilities(model: UNet, inputs: np.ndarray, device: torch.device, batch_size: int) ->
    np.ndarray`: float32 `(n, y, x)` sigmoid, NaN where the `trusted` channel (last) is 0; `torch.no_grad`, eval mode.
  - `unet_labels(p: np.ndarray, obscured: np.ndarray, p_star: float) -> np.ndarray`: uint8; 1 where `p >= p_star`,
    0 below, 255 where NaN, 2 where obscured (spec U8).
  - `@dataclass(frozen=True) class UNetModel: setting: str; options: dict; state_dict: dict; normalization:
    Normalization; p_star: float; input_channels: list[str]; base_channels: int; depth: int; label_attrs: dict;
    torch_version: str; fogseg_version: str`.
  - `network(model: UNetModel) -> UNet` (weights loaded, eval mode, on cpu).
  - `save_unet(model: UNetModel, path: Path) -> None` (`torch.save` of a plain dict to `path.part`, then rename) and
    `load_unet(path: Path) -> UNetModel` (`weights_only=True`; refuses `input_channels != INPUT_CHANNELS`;
    `FileNotFoundError` naming `fogseg train` when missing).

### Task 6: MLflow tracking and `fogseg train`

**Files:**
- Modify: `src/fogseg/tracking.py` (add `MlflowTracker`), `src/fogseg/cli.py` (`cmd_train`, parser), `configs/default.yaml`
- Create: `tests/test_tracking.py`, `tests/test_unet_command.py`

**Interfaces:**
- Produces:
  - `MlflowTracker(tracking_uri: str, artifact_dir: Path, experiment: str)`: creates the experiment with
    `artifact_location=artifact_dir.as_uri()` if missing; same methods as `NoTracker`; `run` yields the run id and
    nests under the active run when `nested=True`; `resume(run_id: str)` context manager for `evaluate`. Params
    are flattened (`unet.epochs`, …) and stringified by MLflow; values longer than MLflow's limit are cut to it.
  - `cmd_train(args)` (`fogseg train [--config] [--season]`):
    1. `require_tune_season`; refuse with `FileExistsError` if `stations/unet_held_out.csv` or `.json` exists.
    2. `selection, _ = experiment_cases(cfg, season)`; label store `label_store_path(output_dir, labels.mode)`;
       `check_labels_match(data, labels)`.
    3. Scenes: `tune_season_scenes` ∩ night fold < `n_folds`; elevation from
       `read_static(data, dem_path, ["terrain"]).elevation_mean`; `read_inputs`; `fit_normalization` on all of them
       (ruling U13: one normalization from the final model's training scenes, shared by the CV folds);
       `model_inputs`; `read_targets` for every target the settings use (a store without `fog_probability`
       makes the soft settings refuse, with the message of `targets`).
    4. Parent run `"train"` with params: the `unet:` section, `labels.mode`, the label store's `teacher_setting`
       and `teacher_p_star` if present, `n_scenes`, `n_points`, `device`.
    5. `cross_validate_unet` → `winner(table)` from `experiment.py`; p* = the winner's pooled `value`.
    6. Final fit on all scenes with the winner's options, seed `stations_cfg["seed"]`, in a nested run `"final"`;
       `save_unet` with `label_attrs` = the label store's attributes.
